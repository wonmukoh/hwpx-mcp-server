# HWPX MCP

한글 문서(HWPX)를 **한글 없이** 읽고 쓰는 MCP 서버.

- **규격**: MCP — SDK 가 받는 **다섯 판을 다 받는다**
  (`2025-11-25` `2025-06-18` `2025-03-26` `2024-11-05` `2024-10-07`).
  모르는 판이 와도 거절하지 않고 아는 최신 판으로 답한다.
- **대상**: Claude · Codex · Gemini · 안티그래비티 — **이름이 아니라 규격판으로 붙는다**
- **목표**: 한글이 하는 일을 그대로 한다. 지금 쓰고 있는 MCP 와 **대등하거나 그보다 낫다.**

---

## 왜 다시 만드나

지금 쓰는 MCP(`MCP/hwpx-mcp-작업/`)를 며칠 붙들고 고쳤다. 열일곱 차례에 걸쳐 고친
버그가 거의 다 **같은 뿌리**에서 나왔다.

> XML 을 문자열로 보고 정규식으로 수술한다.

`<hp:p>` 를 찾는 정규식이 `<hp:pic>` 을 물고, `<hp:footNote>` 를 찾는 검사식이
`<hp:footNotePr>` 에 걸린다. 문단의 끝을 '첫 번째 `</hp:p>`' 로 잡아서 각주 안에
미주가 들어간다. 이런 것들은 **XML 검사를 통과한다.** PDF 로 뽑아 눈으로 보기 전에는
아무도 모른다.

고칠 때마다 같은 함정을 또 밟았다. 뿌리를 안 건드렸기 때문이다.
자세한 것은 [`기획/01-왜-다시-만드나.md`](기획/01-왜-다시-만드나.md).

### 도구가 열한 개인 까닭

옛 MCP 는 **125개**다 (직접 물어서 센 수다 — 기획 문서에 156이라 적혀 있던 것은
어림한 값이었고, 틀렸다). 그만큼 `tools/list` 가 먼저 컨텍스트를 먹고,
모델은 어느 것을 쓸지 헷갈린다.

| | 옛 MCP | 여기 |
|---|---|---|
| 도구 | 125개 | **11개** |
| `tools/list` 답 | 71,926자 | **18,211자** |

두 수 다 서버에 `tools/list` 를 보내 받은 것이다.

여기서는 **읽기 다섯 · 문서 넷 · 쓰기 둘**이다.
쓰기는 `compose`(새로 쓴다)와 `edit`(있는 것을 고친다) 둘뿐이고,
`edit` 은 `op` 로 가른다 — `set_text` · `replace` · `set_style` ·
`insert_row` · `insert_image`. 옛 MCP 가 열한 개로 쪼갠 것이 이 하나에 들어 있다.

### 재 본 것

**양식을 도구만으로 채우기**
학교 문서 양식 셋을 **MCP 도구만으로** 열어 채우고 저장했다.
한 곳만 고쳤을 때 문단·표 수가 그대로이고 **달라진 픽셀이 0.04~0.07%** 다.

**양식을 열고 그대로 저장하기**
정부 문서 4편·기준 파일 12개, 57판. 29쪽짜리까지 **다른 픽셀 0**.
표 65개 427칸을 다 채워도 쪽 수와 표 기하가 그대로다.

**세 클라이언트**
Claude(2025-06-18) · Codex(2025-03-26) · Gemini(2024-11-05) 가
각자 다르게 두드려도 같은 도구를 보고 문서를 만든다.

### 아직 안 되는 것

정직하게 적는다. 자세한 것은 [`기획/06-계획.md`](기획/06-계획.md) 의 기능표.

- 처음부터 조판할 때 디자인 닮음 **75%** — 글자 크기 57%, 선 42% 가 약하다
- 재현 51쪽 가운데 **35쪽만 실제로 쟀고**, 그 가운데 6쪽이 세로로 넘친다
- 지우기(문단·표), 각주·미주, 수식, 하이퍼링크, 책갈피, 메모, 다단
  — 161편에 다 합쳐 열 편 남짓이라 뒤로 미뤘다

### 오늘 배운 것

같은 함정을 하루에 세 번 밟았다. **있는 것과 쓸 수 있는 것은 다르다.**

- `image` 블록은 조판에 다 있었는데 스키마에 자리가 없어 **모델이 그림을 못 넣었다**
- 그걸 막으려 세운 막이가 **필드 이름이 아무 데나 있으면 통과**시켰다
- **고치는 도구가 통째로 없었다** — 검증이 문서 층을 직접 불러서 못 봤다

세 번째는 Draftsmith 세션에 "너희가 쓰는 도구를 알려 달라" 고 물어서야 알았다.
그래서 `검증/양식도구.mjs` 는 **도구만** 쓴다. 모델이 걷는 길과 같은 길이다.

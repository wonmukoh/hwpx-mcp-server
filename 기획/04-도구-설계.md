# 04. 도구 설계

**28개.** 지금 MCP 는 100개가 넘는다. 도구를 줄이고 매개변수에 깊이를 준다.

기준: 비슷한 도구가 여럿이면 **하나로 합치고 매개변수로 가른다.**
`insert_table_row` / `insert_table_column` / `delete_table_row` / `delete_table_column`
넷은 `resize_table` 하나가 된다.

---

## 매개변수 사전

**여기 없는 이름은 만들지 않는다.** 새 이름이 필요하면 이 표에 먼저 넣는다.

| 이름 | 뜻 | 형 |
|---|---|---|
| `doc_id` | 문서 손잡이 | string |
| `id` | 요소 ID (`p_3f2a`, `tbl_9c1`, `cell_9c1_0_2`) | string |
| `ids` | 요소 ID 목록 | string[] |
| `at` | 넣을 자리 — `"end"` `"start"` `"after:<id>"` `"before:<id>"` | string |
| `section` | 구역 번호. 기본 0 | integer |
| `row` `col` | 칸 좌표. 0부터 | integer |
| `rows` `cols` | 개수 | integer |
| `text` | 글 | string |
| `phrase` | 문단 안에서 찾을 어구 | string |
| `align` | `left` `center` `right` `justify` | string |
| `valign` | `top` `middle` `bottom` | string |
| `font` | 글꼴 이름 | string |
| `size` | 글자 크기 **pt** | number |
| `color` | 글자색 `#RRGGBB` | string |
| `bold` `italic` `underline` `strike` | 글자 꾸밈 | boolean |
| `background` | 배경색 `#RRGGBB` | string |
| `gradient` | 그라데이션 색 2개 이상 | string[] |
| `border` | 테두리 — `"SOLID 0.4 #1F4E9C"` 한 문자열 | string |
| `sides` | 테두리를 걸 면 — `all` `left` `right` `top` `bottom` | string[] |
| `width` `height` | 크기 **pt** | number |
| `indent_first` `indent_rest` | 첫 줄 / 나머지 줄 시작 위치 **pt** | number |
| `space_before` `space_after` | 문단 위·아래 여백 **pt** | number |
| `line_spacing` | 줄 간격 **%** | number |
| `level` | 개조식 단계 1~3 | integer |
| `path` | **절대** 파일 경로 | string |

### 단위는 pt 하나로

바깥으로는 **pt** 만 내놓는다. HWPUNIT(1pt = 100)은 안쪽에서만 쓴다.
용지 크기처럼 mm 가 자연스러운 곳만 mm 를 쓰고 이름에 밝힌다 (`margin_mm`).

단위가 섞이면 모델이 틀린다. 지금 MCP 는 `width: 42520`(HWPUNIT)과
`font_size: 11`(pt)이 같은 도구에 있다.

### 테두리를 한 문자열로 받는 이유

```
"SOLID 0.4 #1F4E9C"    종류 두께(mm) 색
"NONE"                 없음
"DASH 0.5 #C00000"
```

`border_type` / `border_width` / `border_color` 셋으로 나누면 매개변수가 셋 늘고
셋 중 하나만 주는 실수가 난다. 한 문자열이면 **한 덩어리로 보인다.**
파싱 실패하면 쓸 수 있는 값을 전부 적어 돌려준다.

## 도구 28개

### 문서 (5)

| 도구 | 하는 일 | 주석 |
|---|---|---|
| `create_document` | 빈 문서를 만든다 → `doc_id` | |
| `open_document` | 파일을 연다 → `doc_id` | `readOnly` |
| `save_document` | 저장한다. `overwrite` 없이 덮어쓰지 않는다 | `destructive` |
| `close_document` | 닫는다 | |
| `list_documents` | 열려 있는 문서들 | `readOnly` |

`doc_id` 는 불투명하다. 수명(예: 1시간)을 설명에 적는다.
없는 `doc_id` 로 부르면 **"다시 여세요" 까지 말한다.**

### 읽기 (4)

| 도구 | 하는 일 |
|---|---|
| `get_outline` | 문서 뼈대 — 요소 ID·종류·미리보기. **탐색은 여기서 시작한다** |
| `get_content` | 요소 하나 또는 범위의 내용. 서식 포함 여부 선택 |
| `find` | 글·표 머리글·스타일로 찾는다 → ID 목록 |
| `get_styles` | 문서에 정의된 글자·문단·테두리 모양 |

넷 다 `readOnlyHint: true`. 호스트가 확인 없이 통과시킬 수 있어 **탐색이 가벼워진다.**

### 조판 (1) — 기본 경로

| 도구 | 하는 일 |
|---|---|
| `compose` | 블록 목록으로 문서를 쓴다 |

```jsonc
compose({
  doc_id,
  page: { border: "SOLID 0.4 #1F4E9C", header: "…", page_number: true,
          title_font: "맑은 고딕", body_font: "함초롬바탕" },
  blocks: [
    { kind: "title",   text: "2026년 주요업무 추진계획", date: "2026. 3.", org: "교 육 부" },
    { kind: "band",    text: "Ⅰ. 추진 배경", background: "#1F4E9C", color: "#FFFFFF" },
    { kind: "outline", emphasize: ["조기 개입"], items: [
        { level: 1, text: "학생 한 명도 놓치지 않는 책임교육", bold: true },
        { level: 2, text: "기초학력 미달 비율이 3년째 늘고 있어 조기 개입이 필요하다" } ] },
    { kind: "box",     text: "세 과제를 한 흐름으로 묶어 추진한다" },
    { kind: "titled_box", text: "< 핵심 추진과제 >", items: [...] },
    { kind: "page_break" },
    { kind: "table",   headers: ["구분","2025년","2026년"], rows: [["기초학력","1,240","1,580"]] },
    { kind: "cells",   header_row: ["추진과제","세부 내용"], rows: [[...],[...]] },
    { kind: "image",   path: "C:\\...\\chart.png", caption: "〈그림 1〉 연도별 투자 추이" },
    { kind: "text",    text: "※ 단위: 억 원", size: 9 },
  ],
})
```

- **위치 번호가 없다.** 순서대로 앉는다.
- 만든 것의 ID 를 전부 돌려준다 → 뒤에 손볼 때 쓴다.
- 블록 종류는 **정부 문서에서 실제로 쓰이는 것만.**
  처음엔 "도형은 0개"라고 적었는데 교육부 문서 한 편만 보고 내린 판단이었다.
  113편을 세니 `rect` 24편·`container` 13편·`line` 4편이 나왔다.
  **도형 블록도 만든다** ([`../자료/실측.md`](../자료/실측.md) 4항).

### 글 편집 (4)

| 도구 | 하는 일 |
|---|---|
| `set_text` | 요소(문단·셀)의 글을 바꾼다. 서식은 지킨다 |
| `replace_text` | 문서 전체에서 찾아 바꾼다. 양식 채우기용 |
| `emphasize` | **문단 안 어구만** 서식. 정부 문서가 줄마다 쓴다 |
| `set_style` | 글자 모양 + 문단 모양. `text_*` / `para_*` 로 가른다 |

`set_style` 하나로 합친 이유: 실무에서 "가운데 정렬하고 굵게" 를 같이 준다.
둘로 나뉘어 있으면 두 번 부르고, 두 번째가 첫 번째를 덮는 사고가 난다.

### 구조 편집 (3)

| 도구 | 하는 일 | 주석 |
|---|---|---|
| `insert_element` | 낱개 삽입 — 문단·쪽나눔·그림·각주·미주·링크·책갈피 | |
| `delete_element` | 지운다 | `destructive` |
| `move_element` | 옮긴다 | |

`kind` 열거로 가른다. 종류마다 쓰는 값이 다른 것은 설명에 적는다
(스키마로 가르면 `oneOf` 가 필요한데 **금지**다 — [`03`](03-MCP-규격과-범용성.md) 규칙 2).

### 표 (6)

| 도구 | 하는 일 |
|---|---|
| `insert_table` | 표를 넣는다 → `tbl_*` ID |
| `set_cell` | 칸 하나 또는 범위 — 글·여러 문단·서식·배경·테두리·대각선·정렬·여백 |
| `merge_cells` | 병합. 되돌리기는 `split: true` |
| `resize_table` | 행·열 넣고 빼기, 폭·높이 |
| `fill_table` | 표를 자료로 한 번에 채운다. 양식 채우기용 |
| `fit_table` | 행 높이를 내용에 맞춘다 + 기하 검사 |

**`set_cell` 이 표의 중심이다.** 지금 MCP 는 `set_cell_style` / `set_cell_properties` /
`update_table_cell` / `set_cell_paragraphs` 넷으로 흩어져 있다.

```jsonc
set_cell({ doc_id, id: "tbl_9c1", row: 0, col: 0, to_row: 0, to_col: 3,
           background: "#1F4E9C", color: "#FFFFFF", bold: true, align: "center",
           valign: "middle", border: "SOLID 0.12 #000000", sides: ["all"],
           paragraphs: [ { text: "추진과제", level: 1 }, { text: "세부", level: 2 } ] })
```

지금 없는 것 중 넣을 것: **칸 안쪽 여백**(cellMargin), **머리행 반복**(repeatHeader),
**표 정렬**(가운데 놓기), **표 바깥 여백**.

### 쪽 (2)

| 도구 | 하는 일 |
|---|---|
| `set_page` | 용지·방향·여백·테두리·배경·단 |
| `set_running_head` | 머리말·꼬리말·쪽번호. 글과 로고 그림 |

둘 다 `idempotentHint: true`.

### 검증 (2)

| 도구 | 하는 일 |
|---|---|
| `validate_document` | 규격·표 기하·무결성 검사 → 문제 목록 |
| `render_preview` | 한글로 PDF/PNG 를 뽑는다 (Windows + 한글 필요) |

`render_preview` 는 **한글이 없으면 없다고 분명히 말한다.**
서버의 다른 기능은 한글 없이 전부 돌아간다.

### 안내 (1)

| 도구 | 하는 일 |
|---|---|
| `get_guide` | 작업 흐름 안내 — 새 문서 / 양식 채우기 / 표 다루기 |

모델이 처음에 이걸 한 번 부르면 나머지를 덜 헤맨다.

## 두 갈래 흐름

도구 설명에 이 두 그림을 넣는다.

### 문서를 새로 쓴다

```
create_document → compose → (필요하면 emphasize / set_cell) → save_document
```

### 남의 양식을 채운다

```
open_document → get_outline → find → replace_text / fill_table / set_text → save_document
```

**양식을 채울 때는 원본 조판을 안 건드린다.** 표 높이 자동 맞춤도 안 한다
(우리가 만든 표에만 한다). 남의 문서를 망치지 않는 것이 먼저다.

## 결과 모양

모든 도구가 같은 모양으로 답한다.

```jsonc
{
  "resultType": "complete",
  "content": [
    { "type": "text", "text": "표 3개, 문단 41개" },          // 사람이 읽는 요약
    { "type": "text", "text": "{\"tables\":3,\"paragraphs\":41}" }  // 구버전 호환
  ],
  "structuredContent": { "tables": 3, "paragraphs": 41 }
}
```

실패는 `isError: true` 에 **다음 수까지** 적는다.

```
표 3번을 찾지 못했습니다. 이 문서에는 표가 2개 있습니다(tbl_9c1, tbl_4a7).
get_outline 으로 ID 를 확인하세요.
```

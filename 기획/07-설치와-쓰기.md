# 설치와 쓰기

이 MCP 를 세 클라이언트(Claude·Codex·Gemini)에 붙이는 법.

> 아직 배포 전이다. 지금은 **소스에서 바로** 돌린다.
> `npx hwpx-mcp` 는 7단계에서 연다.

---

## 무엇이 필요한가

| | 왜 |
|---|---|
| Node 20 이상 | 서버가 순수 Node 로 돈다 (`bin/hwpx-mcp.mjs`) |
| 한글(HWP) | **없어도 된다.** 문서를 만들고 고치는 데는 안 쓴다. 검증에만 쓴다 |
| Python + pymupdf | **없어도 된다.** 눈으로 재는 검증에만 쓴다 |

문서를 만드는 데는 Node 하나면 된다. 한글이 깔린 기계가 아니어도 돈다 —
그게 이 MCP 를 다시 만든 까닭 가운데 하나다.

---

## 소스에서 돌리기

```
git clone <이 저장소>
cd "HWPX MCP"
npm install
npm run build
node packages/server/bin/hwpx-mcp.mjs      # stdio 로 붙는다
```

`hwpx-mcp: stdio 로 붙었다` 가 stderr 에 뜨면 산 것이다.

---

## Claude Code / Claude Desktop

`~/.claude.json` (또는 Claude Desktop 의 `claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "hwpx": {
      "command": "node",
      "args": ["C:\\곳\\HWPX MCP\\packages\\server\\bin\\hwpx-mcp.mjs"]
    }
  }
}
```

> **경로에 한글이 있으면** 따옴표 안에 그대로 쓴다. 윈도우에서 역슬래시는 두 번(`\\`) 적는다.

## 안티그래비티 (Antigravity)

`~/.gemini/config/mcp_config.json`:

```json
{
  "mcpServers": {
    "hwpx": {
      "command": "node",
      "args": ["C:\\곳\\HWPX MCP\\packages\\server\\bin\\hwpx-mcp.mjs"],
      "disabled": false
    }
  }
}
```

`~/.gemini/settings.json` 이 아니라 **`~/.gemini/config/mcp_config.json`** 이다.
같은 `.gemini` 아래에 있어도 Gemini CLI 와 다른 파일을 본다.

> **양식을 채우게 시킬 때는 첫 판을 열어 보라.** 안티그래비티가 열어 둔 양식을 놔두고
> `compose` 로 **새 문서를 지어 딴 폴더에 저장한** 일이 있다. 도구 설명에
> 「채울 양식이 이미 열려 있으면 쓰지 마라」 를 넣어 두었지만,
> 그 고침을 안티그래비티로 다시 재 본 적은 없다.

## 그 밖의 클라이언트

**규격판만 맞으면 붙는다.** 이름을 세지 않는다.

    2025-11-25 · 2025-06-18 · 2025-03-26 · 2024-11-05 · 2024-10-07

`검증/세클라이언트.mjs` 가 이 다섯 판에 **모르는 판 하나(2099-01-01)** 를 더해
여섯 가지로 두드려 본다. 모르는 판을 보내도 서버는 거절하지 않고
**제가 아는 최신 판으로 답한다** — 규격이 그렇게 하라고 한다.
안 그러면 새 클라이언트가 나올 때마다 안 붙는다.

여섯 판 다 **같은 도구 열한 개**를 보고 문서를 만드는 것까지 잰다.

## 붙었나 보는 법

도구 열한 개가 보이면 된다:

```
create_document  open_document  save_document  close_document  list_documents
get_outline      get_content    find           get_styles      compose
edit
```

열한 개다. **적다는 것이 이 도구의 성질이다** — 지금 쓰는 MCP 는 **125개**이고,
`tools/list` 답이 71,926자다. 여기는 18,001자다.
(둘 다 서버에 물어서 받은 수다. 예전에 156개라 적어 둔 것은 어림한 값이었다.)

### 소스를 고쳤으면 **다시 구워야** 한다

깔린 서버가 물고 도는 것은 `dist` 다. 소스를 고쳐도 **다시 굽기 전까지는 옛 동작이다.**

```
npm run 배포굽기
```

`npm test` 는 이제 이것도 같이 한다. 낱개 갈래만 돌렸으면 손으로 한 번 굽는다.
실제로 겪었다 — 도구 셋을 고치고 검증을 다 돌렸는데,
`dist` 를 물고 있던 쪽은 **옛 동작을 그대로 보고 있었다.**

## 자주 걸리는 것

**"경로가 절대 경로가 아니다"**
상대 경로는 안 받는다. MCP 서버가 어느 폴더에서 도는지 모델도 사람도 모르기 때문이다.

**"이 문단에는 글이 없고 hp:tbl 이 들어 있다"**
표가 든 문단을 글로 고치려 한 것이다. 표 안에 쓰려면 셀 ID(`cell_…`)로 가리킨다.

**"고치기 전에는 없던 흠 N건이 생겨 저장을 멈춘다"**
우리가 낸 흠이다. 원래 있던 흠은 안 막는다 — 늘어난 것만 막는다.
`기록()` 에 무엇을 했는지 남아 있으니 마지막 연산을 되짚는다.

**"모르는 인자다. 쓸 수 있는 것: …"**
쓸 수 있는 이름을 다 알려 준다. 그대로 골라 다시 부르면 된다.

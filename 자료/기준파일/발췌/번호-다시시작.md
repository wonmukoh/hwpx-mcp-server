# 번호-다시시작

newNum — 쪽/그림/표 번호를 다시 시작

출처: `교육부-2026대학혁신지원사업-기본계획.hwpx`

## 바로 앞

```xml
NEWSPAPER" layout="LEFT" colCount="1" sameSz="1" sameGap="0"/>
</hp:ctrl>
</hp:run>
<hp:run charPrIDRef="157">
<hp:ctrl>
<hp:pageNum pos="BOTTOM_CENTER" formatType="DIGIT" sideChar="-"/>
</hp:ctrl>
<hp:ctrl>
```

## 이 요소

```xml
<hp:newNum num="1" numType="PAGE"/>
```
